---

## 2. Программно-технический стек и используемые инструменты

При реализации проекта использованы следующие инструменты, библиотеки и технологии:

1. **Среда выполнения и язык:**
   * Python (версия 3.13)
   * Jupyter Notebook / Visual Studio Code

2. **Библиотеки анализа данных и математических расчетов:**
   * `pandas` — загрузка, агрегация, фильтрация и табличный анализ данных.
   * `numpy` — статистические вычисления и векторные операции.

3. **Библиотеки визуализации данных:**
   * `matplotlib.pyplot` — построение гистограмм, точечных диаграмм и временных рядов.
   * `seaborn` — стилизация и оформление графических материалов (`seaborn-v0_8-whitegrid`).

4. **Инструменты сбора данных (Web Scraping):**
   * `requests` — HTTP-запросы к ресурсу с исходной статистикой (`Scrape This Site`).
   * `beautifulsoup4` (`bs4`) — разбор и парсинг HTML-таблиц.

5. **Вспомогательные инструменты и справочные материалы:**
   * Официальная документация библиотек Pandas и Matplotlib.
   * Официальный статистический справочник и исторический регламент NHL Records (справочно для валидации аномалий регламента).
   * ИИ-ассистент (Gemini 3.8 Flash) — вспомогательное применение в рамках практики pair-programming (проверка синтаксиса при рефакторинге графиков Matplotlib, вычитка пояснительного текста на академическую строгость и орфографию).
